# The mixed-line shards (kogany plan docs/plans/kogany/kogany-yellowback-plan.md §5 "mixed-regtest",
# §4.2 rule 4; workspace docs/plans/kogany/ci-design.md): every Yellowback functional script of
# yellowback-tests.yml's YELLOWBACK_SCRIPTS, run unchanged with kogany (koganyd) followers
# (KOGANY_BIN, qa/rpc-tests/test_framework/kogany.py). The `mixed` job of yellowback-tests.yml runs
# one group per job; qa/kogany_mixed_shards.py reads this file (`check` keeps it complete).
#
#   <group> <script> <state> <wave> [flags...]
#
#   group   vault | yed | fees | attest | node: one CI job each, re-run on its own
#   state   report  runs, failure reported (the job stays green)
#           gate    runs with KOGANY_STRICT=1, failure fails the job (and the `mixed tier` check)
#           The coordinator flips a script from report to gate when its wave's gate is seen green
#           (coordination-handoff §7); one word per script, in a reviewed commit.
#   wave    the wave whose gate names the script (plan §3: W2-d, W4-e, W5-f, W6, W7, W8; W9-b for
#           the rest, "the whole suite in mixed mode")
#   flags   mirror   KOGANY_MIRROR_INVALIDATE=1 (the script calls invalidateblock/reconsiderblock)
#           mempool  KOGANY_MEMPOOL=1 (getrawmempool set equality and tx verdicts, W6)
#           direct   not an rpc-tests.py entry: run the file itself (rpc-tests.py drops unknown names)
#
#   excluded <script> <reason>     never in a mixed shard (the run without KOGANY_BIN still has it)
#
#   report rows kogany cannot follow (W9-b finding 1, "no-ycash-upgrades"): stopatheight,
#   ycash_bootstrap, lightwalletd_only, vault_pq_wallet, vault_pq_wallet_restore and
#   wallet_pq_address run regtest chains without the Ycash upgrades below Canopy (the framework's
#   200-block cache, or Vault alone by -nuparams); kogany follows only chains with the Ycash
#   upgrades at 1 (cumulative upgrades, K-6). They stay `report` in their mixed group so the
#   sidecar column (the pair mines its own Ycash chain) keeps them; they are never flipped to gate.
